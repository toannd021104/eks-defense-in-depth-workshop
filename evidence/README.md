# Verification evidence

`verification.json` is generated by real AWS/Kubernetes probes. Its diagnostics redact account IDs, and it contains no credentials. PASS applies only to the named test and the recorded time. Console screenshots show actual deployed lab resources, not simulated UI.

Detailed command output, registry credentials, federation tokens, private signing keys and kubeconfigs stay under `.local/` and are excluded from Git/Hugo. The lab is left running for review; full teardown has not been executed during the authoring run.
